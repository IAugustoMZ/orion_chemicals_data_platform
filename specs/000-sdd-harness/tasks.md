## Loop limits

The build agent runs `poetry run sdd verify 000` after each task. After **3** consecutive
failing verifications on the same task it stops and asks us
([AI control plane](../../harness/ai-control-plane.md#loop-limits-and-escalation)).

For this bootstrap dossier `sdd verify` cannot run before G4 (it refuses, by design); the
equivalent checks were run directly with each tool (see `validation.md`). The default loop
limit applies to every later change of the harness.
